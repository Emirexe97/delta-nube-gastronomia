01 / SOLICITÁS

Prepará tu página

Con la instalación aprobada, entrá a Configuración → Página web. Durante el alta inicial, buscá Configuración → Licencia. Elegí un subdominio y cargá un WhatsApp; tocá Solicitar. No necesitás una cuenta ni un código de emparejamiento.

02 / PUBLICÁS

Tu carta al día

En Productos, activá Mostrar en la web para lo que quieras publicar. Con el POS conectado, los precios para retiro y delivery se sincronizan con la carta.

03 / COMPARTÍS

Abrí, copiá o imprimí

Desde Página web podés Abrir carta, Copiar enlace y Descargar QR. El QR se guarda como imagen PNG, listo para imprimir y compartir.
