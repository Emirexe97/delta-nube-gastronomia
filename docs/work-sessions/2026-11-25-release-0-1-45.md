# 2026-11-25 — Delta Nube Gastronomía 0.1.45

## Objetivo

Integrar las mejoras locales del POS y preparar instaladores manuales de la misma versión para Windows x64, macOS Apple Silicon y macOS Intel. La 0.1.44 ya se entregó para Mac desde una rama de build independiente.

## Alcance

- Caja e informes: historial paginado, tablas extensas desplazables, mejoras en la atribución de cobros y procesamiento de impresión.
- Catálogo, salón y compras: mejoras de edición y búsqueda; migraciones SQLite 59–61 para índices, revisión de menú y columnas de búsqueda.
- Pedidos web: compresión de catálogos con retorno a JSON sin comprimir ante 400/415; cambios en sincronización, pedidos y Comandas. El push no despliega el servicio.
- Licencias: el empaquetado manual mantiene appId, configuración pública y perfil. No se publica un feed ni se habilita el updater.

## Verificación previa al push

- `corepack pnpm typecheck --force`: 11/11 tareas; `corepack pnpm build`: 11/11 tareas.
- Desktop unitario: 201 aprobadas, 1 omitida; dominio repetir pedido: 6/6; web focalizado: 39/39.
- E2E nativo focalizado: 3/3 (paginación e informes extensos de Caja, conciliación de Finanzas), con perfiles descartables.
- Tres fallas del demo general (informes de cajas históricas y dos escenarios de liquidaciones) también se reprodujeron en un worktree limpio de la base 8e8b838. Los dos ajustes de pruebas de mitad y mitad no alteran producción.

## Continuidad y rollback

Destino: origin/main. Antes de instalar Windows, comprobar caja cerrada, respaldar el perfil privado y ensayar las migraciones en una copia SQLite. La reversión de fuente es por unidad de commit; no se debe volver a un binario anterior sobre una base ya migrada sin evaluar compatibilidad y las operaciones posteriores. Los binarios, datos privados y resultados de pruebas no se versionan.
